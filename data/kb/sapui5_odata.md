# SAPUI5 and OData

## SAPUI5 basics
SAPUI5 is the SAP framework for browser apps. An app has a component, a manifest, views written in XML and controllers written in JavaScript. OpenUI5 is the open source version.

## Models
The OData V2 model and the OData V4 model bind controls to a service. The JSON model holds local data. Bindings update the view when the model changes.

## OData query options
OData services accept $filter to select rows, $select to choose fields, $orderby to sort, $top and $skip to page, and $count to return the total. Use server side paging for large tables.

## Fiori elements
SAP Fiori elements builds standard pages such as list report and object page from annotations, so less custom view code is needed.
